# Tembo

Безопасный разборщик файлов для Windows: наводит порядок в «Загрузках», на рабочем столе и в любой другой папке.

- **Сначала план.** Tembo показывает, что и куда переедет, а вы снимаете галочки с того, что трогать не нужно.
- **Ничего не удаляет.** Дубликаты (по содержимому, а не по имени) и файлы неизвестного типа переносятся в папку `_Tembo на проверку`.
- **Всё можно отменить.** Каждый разбор записывается в журнал, кнопка «Отменить» возвращает файлы на место.
- **Работает без интернета.** Файлы никуда не отправляются.

Что умеет:

- **Папки тоже.** Смотрит внутрь: игра с `.exe`, HTML-игра, проект (Godot, код), программа, папка картинок или музыки. Непонятные папки оставляет на месте.
- **Установщик или программа.** `DiscordSetup.exe` уйдёт в «Установщики», а `Godot.exe` — в «Программы»: установщики узнаются по имени и по следам NSIS, Inno Setup и других сборщиков внутри файла.
- **HTML-игры.** `.html` с canvas или игровым движком — в «HTML-игры», сохранённая страница вместе с папкой `_files` — в «Веб-страницы».
- **Серии.** Три и больше файлов с одним началом имени (`IZROBOT2_take1.wav`, `IZROBOT2_take2.wav`…) получают свою подпапку.
- **Значки рабочего стола.** Расставляет их колонками: системные, приложения, игры, папки разбора, ваши папки, файлы. Перед разбором запоминает, где стоял каждый значок, и «Отменить» возвращает их на те же места.
- **Помнит «не трогать».** Файлы, с которых вы сняли галочку, в следующий раз останутся неотмеченными.

Названия папок зависят от языка системы: «Документы», «Изображения», «Установщики» или Documents, Images, Installers.

## Скачать

Сборки для Windows собираются автоматически: вкладка **Actions** → последний запуск **Build Windows app** → артефакт **Tembo-Windows**. Внутри:

- `Tembo-Setup-<версия>.exe` — установщик (рекомендуется);
- `Tembo-<версия>-win.zip` — без установки: распакуйте и запустите `Tembo.exe`.

Стекло (Acrylic) в боковой панели работает на Windows 11 22H2 и новее, на Windows 10 панель непрозрачная.

## Разработка

```
npm install
npm start        # запустить приложение
npm test         # тесты логики разбора
npm run dist     # собрать .exe (на Windows)
```

Структура:

- `src/core/` — сканер, правила, план, применение и отмена; не зависит от Electron;
- `src/main.js`, `src/preload.js` — окно и мост к интерфейсу;
- `src/ui/` — интерфейс;
- `test/` — тесты на временных папках;
- `design/mockup.html` — исходный макет интерфейса.
